## Prompt

Use case: illustration-story. Asset type: compact contextual cover for an editorial business workflow automation service page, landscape 3:2. Create a precise, elegant flat technical illustration that makes this concrete action legible without text: a new customer request paper form is checked against a rule, creates an assigned task and sends a confirmation email. Composition: four recognisable objects arranged left to right on a white field with abundant breathing room: an incoming paper request with ruled form fields and a small attached envelope; a small validation gate represented by a crisp square checklist with one check mark; a task sheet with a human assignment silhouette; an outgoing open envelope with a completed sheet. A very fine indigo connector clearly links their sequence. Sparse modern editorial line art with restrained indigo #1a237e outlines, pale cool grey-blue flat fills, one muted warm ochre accent on the incoming request. The objects must communicate form, checking, task and email clearly. No text, letters, numbers, random UI, software dashboard, screens, buttons, decorative blobs, 3D, people or hands, gradients, shadows, diagonal backgrounds, glow or watermark. Front-facing physical document symbols, consistent line weight, clean square geometry. This is a quiet supporting illustration, not an invented application interface. Preserve every object fully within the frame.
